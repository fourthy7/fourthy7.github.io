01 · Platform

Commux.

A network operations portal. Twelve tools that used to live in twelve folders are now behind one login.

Problem

Every automation the team ran lived in its own folder. A script here, a desktop tool there, an Excel macro nobody dared to touch. Nobody had a shared view, nothing kept an audit trail, and restarting one tool killed whatever it was running.

Approach

A Flask and PostgreSQL portal with three roles. Every job runs as its own OS process and reports back through state files, so the portal can restart in the middle of a run. Reports like Linkload (weekly link utilization) and Airwave (daily optical signal) each get a cockpit with a stage rail, a live log, a run history, and a schedule that fires from the server's Task Scheduler.

Impact

Twelve apps sit behind one login. Weekly reports are ready before anyone signs in, and every sign-in and change is written to an audit ledger.

02 · Diagnostics

Traceroute.

See the path every packet takes from a radio site to the core, hop by hop, with the health of each link.

Problem

When a site degraded, someone had to trace the path from radio access to core by hand. The three vendors each describe SRv6 and MPLS tunnels differently, and the only metric history lived in another team's database, which kept just 25 days.

Approach

A traceroute app that logs into every hop through a jump host, handles each vendor's quirks automatically, and draws the path on a map with live health for every hop. Behind it is a PostgreSQL warehouse that I built and own, which ingests utilization, CRC, and signal level every day. The Topology view goes further. It lists every route between two routers and simulates where traffic would land if you moved it.

Impact

The team gets a same-day "needs attention" view across 1.7M+ interfaces. A partner can call the same diagnostics through a key-protected API, and the reroute check never touches a router.

    03 · Under the hood

    More systems.

    The pipelines and engines behind the portals. You never see them, but every report depends on them.

    Data pipeline

    Weekly capacity pipeline

    Weekly partner-link utilization used to mean stitching together multi-gigabyte workbooks by hand. Now it is four stages: extract, build, apply leased-line contracts, and cap at 100%. A verification pass checks every invariant before anything ships. The workbooks are too big to load, so the stream editor rewrites their XML one row at a time.

    Network automation

    Cross-operator interconnect checker

    Every morning it logs into both ends of each flagged interconnect through a jump host and pings across. Each pair gets a remark: OK, advertise the IP, or check the gateway. A live worker pool runs 1 to 15 sessions, failed pairs retry up to three times, and an ETA tracks long runs.

    Parsing at scale

    Multi-vendor log parser

    A single parser reads 15,000+ raw CLI captures from three router vendors into one schema across ten categories. Output streams straight to disk, so million-row results never sit in memory. Every edge case that only appeared at production scale is sanitized, from illegal XML characters to commands that timed out halfway.
