# Caesar Nafiansyah — portfolio

Static site (HTML, CSS, vanilla JS + GSAP/Lenis from CDN). No build step.

## Deploy to GitHub Pages

1. Create a repo named `<your-username>.github.io`.
2. Push everything in this folder (keep `.nojekyll`) to the `main` branch.
3. Repo → Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
4. Open `https://<your-username>.github.io` after about a minute.
5. In `index.html`, replace `USERNAME` in the `og:image` and `og:url` tags with your username, push again, then paste the URL into LinkedIn Post Inspector to refresh the preview.
